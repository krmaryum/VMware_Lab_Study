## Recommended reading

Start with the merged revision in your preferred language for the foundational concepts you have already studied. It includes a consistent Khalid/Finance example, glossary and 24 revision questions with explanations. Use the main 16-section class guides for broader reference, including database partitions, FSMO and schema versions.

The revision files record two historical lesson stopping points. Neither is marked as newly completed; confirm your current class checkpoint before continuing. Revision examples are illustrative, not new practical evidence.

## Main class-guide study route

| Session | Sections | Goal |
|---|---|---|
| 1 | 1–5 | Distinguish accounts, directory services, protocols and SSO |
| 2 | 6–10 | Understand history, topology, cloud identity and login formats |
| 3 | 11–13 | Explain objects, Kerberos, partitions and replication |
| 4 | 14–16 | Learn FSMO, versions, readiness and revision |

Each session can be split into smaller readings. Explain the user's login and folder access in your own words before moving to the practical; the revision guides use Khalid as their consistent example.
