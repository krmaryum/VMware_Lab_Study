# Yahan se shuru karein / Start here

1. ZIP ko extract karein.
2. **DNS_ROMAN_URDU.md** kholein. Agar English chahiye to **DNS_ENGLISH.md** kholein. Dono mein same learning route hai.
3. Pehle sirf Lesson 1 parhein. Checkpoint ka jawab apne alfaaz mein dein, phir Lesson 2 par jayein.
4. Pictures guide ke andar linked hain. `images` folder ko Markdown files ke saath rakhein. GitHub ya image-supporting Markdown preview mein pictures nazar aayengi; plain Notepad mein sirf unka path nazar aayega.
