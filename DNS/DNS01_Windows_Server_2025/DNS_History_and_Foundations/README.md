# DNS History and Foundations — Illustrated Study Bundle

Start with [English notes](DNS_Study_Notes_English.md) or [Roman Urdu notes](DNS_Study_Notes_Roman_Urdu.md). Both cover the same topics in full.

## Suggested study order

1. Name resolution and the hosts-file problem.
2. DNS history, BIND and WINS comparisons.
3. Naming hierarchy, records, zones and query flow.
4. Standalone enterprise redundancy, followed later by AD integration.
5. Review your actual DNS01 installation checkpoint; continue the lab only when ready.

## What is included

- Two complete Markdown theory guides with indexes and source links.
- Four original SVG educational diagrams and the teacher's reminder screenshot.
- Installation_Part1: one unchanged extracted copy of the supplied Windows Server installation bundle, including its 50 screenshots and notes. The two supplied ZIPs were identical.

Extract this ZIP before opening Markdown. Keep the folder structure intact so relative image links display. SVG files can also be opened directly in a browser. Markdown and images can be committed together to GitHub.

The original installation screenshots include earlier mistakes and superseded settings already labeled in those notes. Use the final configuration table. Theory diagrams are conceptual illustrations, not live lab screenshots. No DNS role installation, cloud deployment, AD configuration or network changes were performed for this theory bundle.
