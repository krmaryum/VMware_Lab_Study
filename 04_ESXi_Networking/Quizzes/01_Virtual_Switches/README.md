# ESXi Quiz 01 — Virtual Switches

Extract and open `ESXi_Virtual_Switches_25_MCQs_Dark.html` locally in a browser. Self-contained dark theme; offline, no installation. GitHub displays source, so download HTML to take the quiz.

25 questions: 10 concepts, 10 lab scenarios, 5 troubleshooting. English questions/options with English/Roman Urdu explanations after submission. Topics: standard-switch purpose, VMkernel versus switch, guest vNIC/port group/uplink path, local versus external switching, host-specific configuration, nested networking and evidence limits.

Timer: 20 minutes, 30 minutes or untimed. One point per correct answer; unanswered zero, no negative marking. Timeout auto-submits. Reattempt resets time/answers and shuffles questions/options. Incorrect/unanswered review filter and light print layout included. Refresh clears the attempt; no data uploaded.

Lab context uses desktop-esxi9 management vmk0 at 10.0.0.10. Historical adapter configurations are separate checkpoints, not a live inspection today. A group or uplink existing is not proof that guest traffic, failover or datastore I/O passed.

Suggested repository folder: `04_ESXi_Networking/Quizzes/01_Virtual_Switches/`. Link this README from `04_ESXi_Networking/README.md`. The HTML embeds questions.json; no extra runtime files required.
