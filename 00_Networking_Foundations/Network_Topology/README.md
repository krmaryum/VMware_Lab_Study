3. Review the VLAN example and the six common topology types: bus, star, ring, mesh, tree and hybrid.
4. Use the poster for revision. Poster dekh kar concepts apne alfaaz mein explain karein.

## Key reminders / Yaad rakhne wali baatein

- **Physical topology:** the arrangement of devices and physical connections, including wired and wireless links.
- **Logical topology:** how communication is organized and how data flows.
- A single physical switch can contain multiple logical networks through VLANs. Communication between VLANs requires routing and appropriate policy.
- Mesh designs can provide alternative paths; actual redundancy depends on the links, devices and configuration.
- Workgroup and domain describe computer/account management arrangements; they are not physical topology types.
