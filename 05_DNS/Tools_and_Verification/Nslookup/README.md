# nslookup study notes

- [Roman Urdu notes](Nslookup_Roman_Urdu.md)
- [English notes](Nslookup_English.md)

Start with the command’s two arguments, then output interpretation, forward/reverse tests, server comparison, record types and troubleshooting. Both editions include interactive mode, a practice evidence sheet and revision answers.

These notes use DNS01 .121, DNS02 .122 and DNS03 .123 from the recorded isolated VMnet2 lab. Commands require a working path to that network. Examples are not new measured results.
