# AD DS Class — English and Roman Urdu

<img src="../images/AD DS_ Class-Object-Attribute-Value.png" width="400">


## English

In AD DS, a **class** is a definition that specifies an object’s type and allowed structure. Examples include **user**, **computer**, and **group** classes.

| Term | Meaning | Example |
| --- | --- | --- |
| **Class** | Defines the object type and allowed structure | `user` |
| **Object** | An actual directory entry created according to a class | Khalid’s user account |
| **Attribute** | A property of the object | `department` |
| **Attribute value** | The actual information stored in that property | `Finance` |

**Simple analogy:** Think of a blank employee form. Its design specifies fields such as name, department, and phone number. Similarly, a class definition specifies the allowed attributes and rules. The completed form represents an actual object.

The **schema partition** stores class and attribute definitions. The **domain partition** stores Khalid’s actual user object and its attribute values, including his department.

**Remember:** A class is the definition; an object is an actual entry created according to that definition.

## Roman Urdu

AD DS mein **class** ka matlab object ki category aur us ka allowed structure define karne wali definition hai. **User**, **computer** aur **group** object classes ki misalein hain.

| Term | Matlab | Misal |
| --- | --- | --- |
| **Class** | Object ka type aur allowed structure define karti hai | `user` |
| **Object** | Us class ke mutabiq banayi gayi actual directory entry | Khalid ka user account |
| **Attribute** | Object ki koi property | `department` |
| **Attribute value** | Us property mein stored actual information | `Finance` |

**Aasaan misal:** Ek khaali employee form ko samjhein. Form ka design batata hai ke kaun se fields ho sakte hain—naam, department aur phone number. Class ki definition bhi aise hi allowed attributes aur rules batati hai. Bhara hua form actual object ki misal hai.

**Schema partition** mein classes aur attributes ki definitions hoti hain. **Domain partition** mein Khalid ka actual user object aur us ki attribute values, jaise department, store hoti hain.

**Yaad rakhein:** Class definition hai; object us definition ke mutabiq bani hui actual entry hai.
