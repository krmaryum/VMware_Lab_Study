# AD DS: Resources

## English

A **resource** is something a user, computer, or service wants to access or use, such as a shared folder, printer, or business application.

| Term | Finance example | Question |
| --- | --- | --- |
| Identity | Khalid's domain account | Who is requesting access? |
| Resource | `\\FS01\Finance` | What do they want to access? |
| Permission | Read or Modify | What are they allowed to do? |

Active Directory stores Khalid's account and the `Finance-Access` group. The files are on **FS01**. The file server checks the applicable share and file permissions to decide what Khalid can do.

## Roman Urdu

**Resource** woh cheez hai jo koi user, computer, ya service access ya use karna chahti hai, jaise shared folder, printer, ya business application.

| Term | Finance ki misal | Sawal |
| --- | --- | --- |
| Identity | Khalid ka domain account | Kaun access maang raha hai? |
| Resource | `\\FS01\Finance` | Kis cheez ka access chahiye? |
| Permission | Read ya Modify | Kya karne ki ijazat hai? |

Active Directory mein Khalid ka account aur `Finance-Access` group store hote hain. Asal files **FS01** par hoti hain. File server share aur file permissions check karta hai aur faisla karta hai ke Khalid kya kar sakta hai.
