# AD DS: Identities

## English

An **identity** is how a person, computer, or service is known to the system. In Active Directory, an account object can represent that identity. The sign-in name and department are examples of attributes on a user object.

| Identity type | Lab example | What it represents |
| --- | --- | --- |
| User | `Khalid` | Khalid's domain account |
| Computer | `CLIENT01` | The computer's own domain account |
| Service | `svc-backup` | The account under which a backup service runs |

**Finance folder example:** Khalid signs in using his account (**identity**). The system verifies his credentials (**authentication**). The file server checks whether he has permission to open the Finance folder (**authorization**).

## Roman Urdu

**Identity** ka matlab hai ke system kisi insan, computer ya service ko kis pehchan se janta hai. Active Directory mein account ka **object** us pehchan ko represent kar sakta hai. User object ka sign-in name aur department us ke **attributes** ki misalein hain.

| Identity ki type | Lab ki misal | Kya represent karti hai? |
| --- | --- | --- |
| User | `Khalid` | Khalid ka domain account |
| Computer | `CLIENT01` | Computer ka apna domain account |
| Service | `svc-backup` | Woh account jis ke naam se backup service chalti hai |

**Finance folder ki misal:** Khalid apne account ke naam se sign in karta hai (**identity**). System us ke credentials verify karta hai (**authentication**). File server check karta hai ke usay Finance folder kholne ki ijazat hai ya nahin (**authorization**).
