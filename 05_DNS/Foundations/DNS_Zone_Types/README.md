Read one language in order: zone/server/record → primary → secondary → stub → comparison → AD distinction → verification → revision. Both editions include the same English poster. Keep the images folder beside the Markdown files so it renders in GitHub or a Markdown preview.

The poster's www/mail/db entries and extra NS examples are illustrative, not evidence that they were configured in the classroom lab. The standard file-backed model is distinguished from AD-integrated DNS. Commands are repeat-practice checks, not new measured results.
