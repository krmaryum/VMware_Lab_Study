# Quiz 04 — Secondary DNS Configuration

Extract and open `Secondary_DNS_25_MCQs_Dark.html` in a browser. Offline, self-contained dark-theme HTML. GitHub shows the source; download it to take the quiz.

25 questions: 10 concepts, 10 classroom scenarios, 5 troubleshooting. Topics include read-only full copies, master selection, transfer authorization, AXFR/IXFR, SOA serial/expiry, Notify, separate forward/reverse zones, direct queries, update verification and backup limitations.

English questions/options with English and Roman Urdu explanations after submission. Choose 20 minutes, 30 minutes or untimed. Correct answer = one point, unanswered = zero, no negative marking. Timer expiry auto-submits. Reattempt resets time/answers and shuffles both questions and options. Incorrect/unanswered review filter and print-friendly results included. Refresh clears the attempt; no data is uploaded.

The classroom examples use DNS01 192.168.0.121 as master and DNS02 192.168.0.122 as secondary. Questions are study scenarios, not new live configuration/test evidence. The HTML embeds its bank; questions.json is an editable reference and is not fetched at runtime.
