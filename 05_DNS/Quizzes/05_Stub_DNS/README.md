# Quiz 05 — Stub DNS Configuration

Extract and open `Stub_DNS_25_MCQs_Dark.html` locally in a browser. Self-contained, offline dark-theme HTML. Download the file from GitHub to run it; GitHub normally displays HTML source.

25 questions: 10 concepts, 10 classroom lab scenarios, 5 troubleshooting. Covers authority metadata, masters versus NS lists, forward/reverse stubs, DNS03 query interpretation, caching and authority availability, and differences from full secondary copies.

English questions/options and short English/Roman Urdu explanations after submission. Choose 20 minutes, 30 minutes or untimed. One point per correct answer; no negative marking, unanswered score zero. Timer expiry auto-submits. Reattempt resets answers/time and shuffles both questions and options. Incorrect/unanswered review filter and light print layout included. Refresh clears the attempt; no data is uploaded.

Classroom values: DNS01 .121 primary, DNS02 .122 secondary, DNS03 .123 stub/resolver for VCPLAB.Com. Scenarios do not claim new live lab tests. A correct recursive answer does not prove a full zone copy or establish the exact packet path.

Suggested repo folder: `05_DNS/Quizzes/05_Stub_DNS/`. Link this README from `05_DNS/README.md`. questions.json is an editable reference; the HTML embeds all questions and needs no separate runtime files.
