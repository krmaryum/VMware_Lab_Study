# Quiz 03 — Primary DNS configuration

Open `Primary_DNS_25_MCQs_Dark.html` locally after extraction. Offline, self-contained HTML with a dark background; no installation required. GitHub displays HTML source, so download the file to take the quiz.

Exactly 25 questions: 10 concepts, 10 classroom lab scenarios and 5 troubleshooting cases. Coverage: DNS Manager, standard primary storage, forward/reverse zones, A/PTR/CNAME, SOA/NS, update policy, evidence interpretation and query diagnostics.

English questions/options; short English and Roman Urdu explanations after submission. Timer options: 20 minutes, 30 minutes or untimed. One point per correct answer; unanswered items score zero. Expiry submits automatically. Reattempt resets answers/time and reshuffles questions and options. Incorrect/unanswered review filter and light print layout are included. Refresh clears the current attempt; no results are uploaded.

Examples use the recorded private VMnet2 classroom lab, not a claim that new changes or tests were executed. Nonsecure updates are a documented isolated-lab choice, not a recommended secure production default.

Suggested repository location: `05_DNS/Quizzes/03_Primary_DNS/`. Link this README from `05_DNS/README.md`. The editable questions.json is included; the HTML embeds its bank and does not fetch the file.
