# DNS Zone Types — Quiz 01

Open `DNS_Zone_Types_25_MCQs.html` in Edge, Chrome or Firefox after downloading/extracting. It works offline without installation. GitHub displays HTML source; download the file and open it locally to take the quiz.

- Exactly 25 single-answer questions: 10 concepts, 10 lab scenarios, 5 troubleshooting.
- English questions and answer choices; each result has English and Roman Urdu explanations.
- Choose 20 minutes, 30 minutes or untimed before starting.
- Submit for score, category breakdown, correct answers and explanation review. Unanswered items score zero.
- Timer expiry automatically submits; tab visibility checks keep it based on the actual deadline.
- Reattempt shuffles questions/options and resets answers and time. “Incorrect and unanswered only” filters the review, not the next full attempt.
- Print results after submission; browser print can save PDF. For a complete print, leave the review filter unchecked.
- No data is uploaded or saved between refreshes. Keep the page open during an attempt.

Suggested repo location: `05_DNS/Quizzes/01_DNS_Zone_Types/`. Link this README from `05_DNS/README.md`. This is the first topic; later quizzes can follow as separate numbered folders.

`questions.json` is the editable bank reference. The HTML already embeds it and does not fetch any separate files. This is self-study material, not a secure exam: answers are included in the downloadable source.
