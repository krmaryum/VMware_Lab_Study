# Quiz 02 — nslookup (dark theme)

Download/extract and open `Nslookup_25_MCQs_Dark.html` locally in Edge, Chrome or Firefox. The HTML is self-contained and works offline. GitHub shows its source; download it to take the quiz.

25 questions: 10 concepts, 10 lab scenarios and 5 troubleshooting questions. English questions/options; English and Roman Urdu explanations appear after submission. Choose 20 minutes, 30 minutes or untimed. Timer expiry submits automatically. One point per correct answer, zero for unanswered, no negative marking.

Reattempt clears the attempt and reshuffles questions and answer options. Review incorrect/unanswered only, or print the full results (light print layout). No attempt data is uploaded or persisted after refresh. Questions.json is an editable reference; no external file is required at runtime.

The dark theme covers the question cards, controls and answer review. Correct/incorrect results have text labels as well as colors.
